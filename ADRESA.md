# Карта адресов alarmsong.com

Задача t072. Этот файл — единственный список того, что на сайте есть и по
какому адресу. **Адреса менять нельзя после того, как они уйдут в магазины:**
Apple и Google хранят ссылку на политику и на удаление данных в карточке
приложения, и битая ссылка там — это отказ на проверке, а не мелочь.

Сайт лежит на GitHub Pages, репозиторий `fishinwork/alarmsong-site`, ветка
`main`, корень репозитория. Домен — в файле `CNAME`.

## Страницы

| Адрес | Файл | Что это | Кто пишет текст | Куда вписан |
|---|---|---|---|---|
| `/` | `index.html` | Главная | чат сайта | — |
| `/support` | `support.html` | Поддержка, пять частых вопросов | юрчат | App Store Connect → Support URL; Play → поддержка |
| `/privacy` | `privacy.html` | Политика конфиденциальности | юрчат | App Store Connect → Privacy Policy URL; Play → Privacy policy; ссылка внутри приложения |
| `/terms` | `terms.html` | Условия использования и EULA | юрчат | App Store Connect → EULA; ссылка внутри приложения |
| `/delete-account` | `delete-account.html` | Как удалить аккаунт и данные | юрчат | Play → Account deletion URL |
| — | `404.html` | Страница «ничего нет» | чат сайта | отдаётся GitHub Pages сама |

**Адреса без `.html`.** GitHub Pages сам отдаёт `support.html` по адресу
`/support`. Так и вписываем везде: короче и переживёт смену движка.

## Служебное

| Адрес | Зачем |
|---|---|
| `/robots.txt` | пускаем поисковики, показываем карту сайта |
| `/sitemap.xml` | пять страниц; при добавлении новой дописать сюда |
| `/site.webmanifest` | имя и иконки для закладки на телефоне |
| `/favicon.ico` | вкладка в старых браузерах, три размера внутри |
| `/favicon.svg` | вкладка в живых браузерах |
| `/apple-touch-icon.png` | плитка на домашнем экране айфона, 180×180 |
| `/icon-192.png`, `/icon-512.png` | иконки из манифеста |
| `/og.png` | картинка, которая показывается при отправке ссылки, 1200×630 |
| `/CNAME` | домен для GitHub Pages; удалить = потерять домен |
| `/brand/` | исходник знака и печка картинок, не страница |

## Соседние адреса, которые к сайту не относятся

Живут не на GitHub Pages, а на нашем сервере и у почты. **Трогать записи DNS
для них нельзя** — на них держатся приложение, станция и письма с кодами входа.

| Адрес | Что |
|---|---|
| `api.alarmsong.com` | сервер приложения |
| `dash.alarmsong.com` | станция наблюдения |
| `send.`, `rsend.` | отправка писем (Resend) |

## Правила, по которым добавляется новый адрес

1. Адрес короткий, из одного слова, без `.html` и без дат.
2. Страница ложится в корень репозитория и дописывается в `sitemap.xml`
   и в этот файл — одним заходом, иначе список разойдётся с правдой.
3. В шапке — знак и слово AlarmSong ссылкой на `/`, в подвале — четыре
   обязательные ссылки. Общий вид берётся из `style.css`, своих цветов
   числами по месту не вписываем.
4. Почта на страницах только `hello@alarmsong.com`. Других ящиков нет.
5. Проверка перед «готово»: ширина 320, 375 и компьютер, светлая и тёмная
   тема, ничего не режется и не уезжает вбок.
